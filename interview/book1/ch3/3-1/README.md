# 운영체제의 큰 그림

운영체제는 핵심 기능을 담당하는 부분을 커널이라고 한다.
대부분 운영체제는 커널을 통해 동작한다.

운영체제는 크게 커널과 시스템 콜로 구분되며, 커널을 통한 핵심 기능은 아래 2가지가 있다.
* 프로세스 및 스레드 관리
  * 프로세스와 스레드
  * 동기화와 교착상태
* 자원 할당 및 자원 관리
  * CPU 관리: CPU 스케줄링
  * 메모리 관리: 가상 메모리
  * 파일/디레겉리 관리: 파일 시스템

## 운영체제의 역할 - 자원할당과 관리

* 자원(resource, 시스템 자원 이라고도 함)은 프로그램 실행에 필요한 요소를 의미

### CPU 관리: CPU 스케줄링

* CPU는 한정된 자원으로 여러 프로그램이 동시적으로 관리될 수 있다.
  * 자원 할당이 다 되었다면, 다른 프로그램의 CPU 사용이 끝날 떄까지 기다렸다가 사용한다.
  * 운영체제는 CPU 스케줄링 기술을 통해 모든 프로그램이 합리적이고 공정하게 CPU를 사용할 수 있도록 관리한다.

### 메모리 관리: 가상 메모리

* 새롭게 실행하는 프로그램을 메모리에 적재, 종료된 프로그램을 메모리에서 삭제
  * 동시에 낭비되는 메모리가 없도록 효율적으로 관리해야 한다.
  * 운영체제는 가상 메모리기법을 통해 효과적으로 메모리를 관리한다.

### 파일/디렉터리 관리: 파일 시스템

* 메모리보다 더 큰 용량을 갖고 있는 보조 긱억 장치는 더욱 일묙요연하게 관리해야된다.
  * 아무렇게나 정보를 저장한다면 정보를 찾기 어렵다.
  * 운영체제는 이를 파일 시스템 기술을 통해 효과적으로 관리한다.

### 그 외, 캐시 메모리와 I/O 장치

* 얘네들도 운영체제가 관리한다.

## 운영체제의 역할: 프로세스 및 스레드 관리

* 프로세스: 실행중인 프로그램
* 스레드: 프로세스를 이루는 실행의 단위 (논리적인 개념)
* 운영체제는 프로세스 및 스레드 관리 기술을 통해 관리한다.

## 시스템 콜과 이중 모드

* 운영체제는 커널 영역(kernel space)과 사용자 영역(user space)로 구분된다.
  * 커널 영역: 운영체제가 메모리에 적재되는 영역
  * 사용자 영역: 사용자 프로그램이 메모리에 적재되는 영역
* 사용자 영역의 응용 프로그램은 System Call을 통해 시스템 자원에 접근해야 된다.
  * 기본적으로 시스템 자원에 접근 할 수 없다.

### 시스템 콜의 호출 순서

* 소프트웨어 인터럽트 발생
  * 자원에 접근하는 입출력 명령어 등을 *소프트웨어 인터럽트*라고 함
  * 발생 시 현재 수행 중인 작업을 백업한다.
* CPU의 커널 모드 전환
  * 운영체제 서비스를 제공받을 수 있는 실행 모드
* 운영체제 코드 실행
  * 시스템 콜을 구성하는 코드 실행
* 사용자 모드로 재전환
  * 운영체제 서비스를 제공받을 수 없는 실행모드로 전환
* 이 과정에서 커널 모드 <-> 사용자 모드 간 실행 모드를 2개로 구분하는 것을 *이중 모드(dual mode)*라고 함
