# 메모리와 캐시 메모리

## RAM의 종류

### DRAM(Dynamic RAM)

* 저장된 데이터가 동적으로 변하는 RAM
* 시간이 지나면 저장된 데이터가 점차 사라진다.
  * 일정 주기로 재활성화 해야 됨.
* 일반적으로 사용하는 RAM이다.
  * 단점이 있음에도 불구하고 소비전력, 가격, 집적도의 장점이 있다.

### SRAM(Static RAM)

* 저장된 데이터가 변하지 않는 RAM
* 속도 등 DRAM 보다 우월하지만, 집적도가 낮아 대용량 설계가 힘듬
  * 캐시 용도로 사용하면 딱임

### SDRAM (Synchronous Dynamic Ram)

* 클럭 타이밍에 맞춰 CPU와 정보를 주고 받을 수 있는 DRAM
  * CPU와 동기화

## DDR SDRAM (Double Data Rate SDRAM)

* 가장 흔히 사용되는 RAM
* 대역폭을 넓혀 속도를 빠르게 만든 SDRAM
  * SDRAM에 비해 속도가 배로 빠름
  * 한 클럭 당 대역폭에 비례 해 CPU와 데이터를 주고 받을 수 있다.
  * DDR2, DDR3, DDR4 각 숫자는 2^n에 비례하는 대역폭

# 메모리의 주소 공간

* 물리 주소와 논리 주소로 구분
* 실제 메모리에 적대되는 프로그램 조각의 물리 주소는 매번 바뀐다.
  * 왜 바뀔까? DRAM의 특성
  * 그래서 논리주소로 메모리 위치를 계산한다.
    * 0번부터 n번까지 사용하겠다.
  * MMU (Memory Management Unit)으로 물리 주소를 변환한다.
    * 실제 메모리의 base + 논리주소로 접근

## 메모리 보호 기법

* 실제 메모리 0~10000번이 있다고 가정
  * 프로그램 A는 1000~2000번을 사용 중
    * 논리 주소가 0~1000번
    * Base 가 1000번 
  * 범위를 초과하는 요청이 들어온다면?
    * A의 1500번지 데이터 제거
    * Memory 2500번지 제거 시도
* 위와 같은 상황 발생 시 다른 프로그램에 영향을 미침
  * 해결하기 위해서 한계 레지스터를 통해 메모리 한계를 계산
  * 한계를 벗어 날 경우, 트랩 인터럽트 발생 -> 실행 중단

# 캐시 메모리

* CPU 내부 캐시: L1, L2
  * 분리형 캐시(split cache)
    * L1I: 명령어만 저장하는 L1
    * L1D: 데이터만 저장하는 L1 
* CPU 외부 캐시: L3

## 참조 지역성 원리

* CPU의 특징을 통해 캐시 예측
  * 시간 지역성 (temporal locality)
    * CPU는 최근 접근했던 메모리 공간에 다시 접근하려는 경향이 있다.
  * 공간 지역성 (spatial locality)
    * CPU는 접근한 메모리 공간 근처를 접근하려는 경향이 있다.
