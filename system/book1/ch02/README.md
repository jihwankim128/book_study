## 정보 단위

* 워드 : CPU가 한 번에 처리할 수 있는 비트
  * 32bit cpu: 4byte
  * 64bit cpu: 8byte
  * 원래 한 글자를 표현하는 단위인줄만 알았다..

## 이진법

* 2의보수
  * 2의 보수는 2진수보다 큰 2^n - 값이다.
  * 단순히 1을 뒤지고 1을 더하는 것이 아니었다.
  * 음수 구분을 위해 플래그를 사용한다.

## 16진법

* 2진수와 변환이 쉬워서 컴퓨터에서 사용하기 편하다.
